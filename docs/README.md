published in `templates/pharo-references/` with the agent templates.

  source, image, compatibility, and skill boundaries.

  verification rules to this repository's packages, baseline, and tests.
- [Pharo guidance bibliography](pharo-guidance-bibliography.md) records the
  public sources behind the published Pharo guidance.
