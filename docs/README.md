# MCP Development Docs

`user/` documents the server for the people and projects that use it.
The rest is for maintaining MCP itself.

`templates/pharo-references/` is neither: it is the guidance installed into
other projects, so it covers Pharo development and the use of a Pharo MCP
server in general, and says nothing about this project in particular.

- [Developing MCP-Pharo](developing-mcp.md) explains repository-specific
  source, image, compatibility, and skill boundaries.
- [MCP-Pharo verification](mcp-verification.md) maps generic live-image
  verification rules to this repository's packages, baseline, and tests.
- [Pharo guidance bibliography](pharo-guidance-bibliography.md) records the
  public sources behind the published Pharo guidance.
- [Getting started](user/getting-started.md), [Building on MCP](user/building-on-mcp.md)
  and [Observability and UI](user/observability.md) are the user-facing set.
